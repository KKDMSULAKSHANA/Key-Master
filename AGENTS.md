# KeyMaster Project Rules

- Use React Navigation with a bottom-tab navigator and native stack; do not use Expo Router.
- Keep the app fully offline. Do not add network calls, remote assets, or network-facing dependencies.
- Do not add dependencies beyond the assignment's approved Expo and navigation stack.
- Work in small, phase-scoped changes and run the relevant validation after each phase.
- Make one normal local Git commit per completed phase using the exact message specified in the assignment. Never push, amend, rebase, or force-push.
